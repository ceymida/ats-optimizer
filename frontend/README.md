# ATS Optimizer — Frontend

Next.js 16 + Tailwind CSS 4 arayüzü. Kurulum ve çalıştırma talimatları için
kök dizindeki [README](../README.md) dosyasına bakın.

```bash
npm install
npm run dev
```

Backend varsayılan olarak `http://localhost:8080` adresinde beklenir.
Farklı adres için `.env.local`:

```
NEXT_PUBLIC_API_URL=http://localhost:8080
```
